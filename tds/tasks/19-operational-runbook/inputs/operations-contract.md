# Operations sandbox
tick processes at most one pending job. Healthy mode marks it sent. Transient mode fails the next failure_remaining attempts. Permanent mode keeps failing. No real email is sent; sent is a sandbox status, so this drill cannot prove downstream delivery. Each attempt increments attempts and preserves payload. Requeue must not resend an already sent job.
Controls: `./tds/lab worker status`, `./tds/lab worker control --mode transient --failures 3`, `./tds/lab worker control --mode permanent`, `./tds/lab worker control --mode healthy`, `./tds/lab worker tick`, `./tds/lab worker requeue --job 1`. SQL can inspect notification_outbox and worker_state. Capture commands and outputs as a drill transcript; set a maximum attempted-recovery count in your runbook. A payload-validation fix or permanent upstream error should escalate rather than loop indefinitely.
